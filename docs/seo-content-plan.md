# SEO content plan – Buddhi Labs Insights

Purpose: build topical authority around HRMS, EV risk intelligence, software development, SEO and IT training, and
route readers to the correct enquiry (`contact.html?interest=…`). All articles are written by "Buddhi Labs Team";
no publication dates are shown until an article is actually published.

Publishing workflow: copy `blog-post-template.html` → `<slug>.html`, replace head metadata and JSON-LD, remove the
draft banner, set robots to `index, follow`, add a card to `blog.html`, add a `<url>` to `sitemap.xml`.
